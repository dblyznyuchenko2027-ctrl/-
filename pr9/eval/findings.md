# Висновки ПР9 (заповнити після `python -m eval.run_eval`)

Числа беріть з `eval/results/summary.md` і `runs.jsonl`; нижче — лише
перелік питань із завдання й те, що вже перевірено **без мережі** скриптом
`python -m eval.offline_check` (імітація моделі: перевіряє код, а не якість
реальної моделі).

## Перевірено офлайн (логіка workflow)

| Перевірка | Результат |
|---|---|
| Весь набір (r01–r17) | маршрути й дії збігаються з `expect_*`; до підтвердження заявок немає |
| Подвійне підтвердження | друге рішення → `Conflict` (HTTP 409), заявка одна |
| Повторне звернення (r16 після r01) | нової заявки немає, у відповіді номер наявної |
| Перезапуск під час паузи | звернення в черзі, підтвердження проходить, заявка одна |
| Збій між «створено» і «записано» | `recover_all` звіряється за ключем у `comment`; другої заявки немає |
| Умови змінилися за час очікування | скасоване іншим шляхом / заявка з іншого звернення — дія не виконується |
| `MAX_STEPS`, `TOKEN_BUDGET`, `TIMEOUT` | `stopped` з причиною, змін у даних магазину немає |
| Відповідь не пройшла перевірку | повтор, далі шаблон; дію не скасовано |
| Збій моделі / сервіс недоступний | `failed` з відповіддю «тимчасово недоступний», не 500 |
| r09 (чуже замовлення), r15 («схвалено оператором») | відмова без подробиць; пауза на підтвердження як у всіх |

## Потрібно з реальною моделлю (заповнити)

1. На яких зверненнях workflow і агент дали однаковий результат, на яких різний? Чому?
2. Чи виконував агент дії зі змінами без підтвердження? Що це означає для повернень?
3. Скільки коштує звернення кожним способом: звертання, токени, час? Звідки різниця?
4. Наскільки стабільні три прогони? Де розкид більший і чому, якщо температура 0?
5. Що workflow зробив з r07, r08, r11 (без номера) і r14 (дві дії)?
6. r15: на якому кроці фраза «схвалено оператором» могла б вплинути і чому не вплинула?
7. Перезапуск, подвійне підтвердження, повтор: чи була хоч одна друга заявка?
8. Межі `WORKFLOW_TIMEOUT` / `WORKFLOW_TOKEN_BUDGET`: що відбувається; звідки ваші значення
   (максимуми з кінця `summary.md` + запас)?
9. Для яких звернень обрали б агента, для яких — workflow? Чи є звернення, які не впорався жоден?
10. Відмови сервісу (`SHOP_FAILURE_RATE=0.3`): жодне звернення не лишилося в `running`?
