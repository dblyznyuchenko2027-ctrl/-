# Політика конфіденційності

## Які дані ми збираємо

Під час реєстрації та оформлення замовлення ми збираємо імʼя, адресу
електронної пошти, номер телефону, адресу або відділення доставки. Під час
користування сайтом — технічні дані: IP-адресу, тип браузера, переглянуті
сторінки, файли cookie. Дані платіжної картки обробляє платіжний сервіс;
магазин їх не отримує й не зберігає.

## Навіщо

Дані потрібні для виконання замовлення, доставки, гарантійного
обслуговування, повернення коштів, роботи програми лояльності та
відповідей на звернення. Технічні дані використовуються для безпеки сайту
й статистики відвідувань.

## Розсилки

Листи про статус замовлення надсилаються завжди. Рекламні розсилки — лише
за згодою, яку можна відкликати в особистому кабінеті або посиланням
унизу будь-якого рекламного листа.

## Кому передаємо

Перевізникам — дані, потрібні для доставки; платіжному сервісу — дані,
потрібні для оплати; сервісним центрам — контактні дані для гарантійного
ремонту. Іншим особам дані не передаються, крім випадків, передбачених
законом.

## Cookie

Сайт використовує обовʼязкові cookie (сесія, кошик) і аналітичні cookie
(статистика відвідувань). Аналітичні можна вимкнути в банері згоди або в
налаштуваннях браузера; без обовʼязкових сайт не працює.

## Скільки зберігаємо

Дані акаунта — доки акаунт існує. Дані про замовлення — 3 роки після
виконання для бухгалтерського обліку та гарантійних зобовʼязань, далі
знеособлюються.

## Ваші права

Ви можете переглянути й змінити свої дані в особистому кабінеті, попросити
копію даних, відкликати згоду на розсилки, видалити акаунт. Запити
надсилайте на пошту служби підтримки; відповідь — протягом 30 днів.

## Безпека

Зʼєднання із сайтом захищене шифруванням, паролі зберігаються у вигляді
хешів, доступ до даних мають лише працівники, яким він потрібен для
роботи. Ми ніколи не просимо повідомити пароль або повні дані картки
листом чи телефоном.
