# Довідники

Дані, з якими правила звіряють вилучене. Модель їх не бачить — вони потрібні коду.

| Файл | Що в ньому | Навіщо |
|---|---|---|
| `company.json` | реквізити «Сузірʼя Рітейл» | рахунок має бути виставлено нам |
| `suppliers.json` | постачальники, з якими є договори: назва, код, IBAN, чи платник ПДВ | постачальник відомий, і гроші підуть на рахунок, який ми знаємо |

У справжній компанії це таблиці в обліковій системі, а зміна IBAN постачальника — окрема процедура з підтвердженням телефоном за відомим номером. Лист чи рахунок із «новими реквізитами» такою процедурою не є.
