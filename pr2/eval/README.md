# Оцінювання якості (перші приклади)

Ця папка — заготовка для збору перших прикладів оцінювання якості детектора.

## Що зробити

1. Покладіть 5–7 зображень із **відомим вмістом** у `eval/images/`
   (наприклад: `photo_01.jpg`, `photo_02.jpg`, ...). Обирайте зображення,
   де ви заздалегідь точно знаєте, що і скільки на них зображено —
   інакше нема з чим порівнювати результат моделі.

2. Заповніть `expected.json` (шаблон уже є): для кожного зображення
   впишіть очікувані об'єкти (клас і кількість) та коротку нотатку про сцену.

3. Прогоніть кожне зображення через застосунок (`/detect`) при
   **двох-трьох різних порогах confidence** (наприклад 0.15, 0.25, 0.5)
   і занесіть результат у `analysis.md` (шаблон нижче).

4. Для кожного розходження між очікуваним і отриманим визначте тип помилки:
   - **пропуск** — об'єкт був, модель його не знайшла;
   - **хибне спрацювання** — модель знайшла те, чого немає;
   - **неправильний клас** — рамка на місці, клас переплутано;
   - **дубль** — один і той самий об'єкт покрито кількома рамками.

5. Коротко опишіть у `analysis.md`, як зміна порогу впливала на кількість
   пропусків проти хибних спрацювань — це і є той компроміс, про який
   ідеться в теоретичній частині роботи.

Це не остаточне оцінювання — лише заготовка (≥5 прикладів + перші
спостереження), яку буде розширено в наступних роботах курсу.
